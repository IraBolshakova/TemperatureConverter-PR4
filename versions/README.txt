Эти три файла — исходные варианты модуля для веток Git.

При подготовке ветки ai-version-1 скопируйте файл:
versions/ai-version-1/temperature_converter.py
в src/implementations/temperature_converter.py, заменив существующий файл.

Для ветки ai-version-2 используйте файл из versions/ai-version-2/.
Для ветки ai-version-3 используйте файл из versions/ai-version-3/.

Каталог versions нужен как памятка для копирования; итоговое сравнение GitHub Actions
проверяет исходный модуль в src/implementations/temperature_converter.py каждой ветки.
